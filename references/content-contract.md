# 内容契约 — 一页纸的唯一内容骨架（V2 · 2026-11-11 定版）

> 一页纸的本质：把**某一个具体方面**讲清楚。四条铁律按优先级排列：
> **忠于内容 > 零线条 > 胶囊化 > 能图不文**。5W2H 只是分析透镜，不是填空表。

## 0. 内容主权（最高优先级）

- **页面结构由内容决定**：先读原始内容，按它自己的分段/层次规划卡片；
  内容没有的模块（WHY / FAQ / 考核挂钩 / 责任人 / 生效时间……）**一律不造、不补、不推**，
  对应 section 直接删除。
- 5W2H 的用法：动笔前用它检查内容讲没讲清楚（谁/何时/怎么做到什么程度），
  **缺了不填**，在交付说明里提示用户补；绝不代编。
- 标题、副题、模块名是"媒体的必要包装"，允许从内容提炼；除此之外不做发挥。
- 例：源内容只有"到货暂养/出货检查/打包"三段 → 就出三张卡，没有 FAQ 就不放 FAQ 区。

## 1. 判页

是一页纸：**单主题**，能用一句话说清「要让谁、做什么」。
不是一页纸：多主题混合通报（拆分）、完整论证制度（解读文档）、
持续数据分析（`ddmc-analysis-report`）、排名海报（`ddmc-referral-poster`）。

## 2. 视觉三原则

1. **零分隔线**：禁用一切实线/虚线边框。模块区分靠：白卡片（浮于浅底）+ 色块面板 + 留白；
   引用/注意类内容用圆角色块 quotes。
2. **胶囊化**：所有标签、标记、徽章用圆角胶囊（border-radius:999px）：
   类目 chips、状态 tag、处罚 tag、✓/✗ 清单用色块面板内符号，不画线。
3. **能图不文**：内容里的**流程、对比、构成、数量关系**，能用静态内嵌 SVG/图形
   更清楚表达就画图，不写干瘪长文字（如：左右对比→双栏色块；公母形状→SVG 剪影；
   步骤流→编号胶囊+箭头；权重变化→dumbbell）。图必须静态渲染、零依赖、无动画。

## 3. 色板（V2.1 定版，token 见模板 :root）

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 `--pri` | `#009999` 青蓝 | 头带、卡片编号、行标签、正向图形（TOP 榜、达标条形） |
| 次要色 `--green` | `#00A500` 叮咚绿 | ✓ 必做/正向语义、正向 delta |
| 强调色 `--red` | `#E34234` 朱砂红 | ✗ 禁止/红线、BOTTOM 榜、恶化指标 |
| 文字 `--ink` | `#32312D` 墨色 | 正文与标题（**禁纯黑 #000**） |
| 警示 `--orange` | `#F37021` 爱马仕橙 | 注意/案例警示面板 |
| 浅底 | 各色 tint（pri-bg/green-bg/red-bg/orange-bg） | 面板底色，色块区分全靠它们 |

## 4. 密度与高度

- 宽度固定 960px；**默认一屏：目标 ≤1700px**（960:1700 ≈ 手机满屏）。
- 内容密集时允许拉长——但每一段内容都要值得那行像素；删减顺序：
  重复信息只在最清晰的一处保留 → 短句化 → 拆页。
- 字号地板：正文 ≥14.5px（rows）/ 步骤动作 ≥17px / H1 ≥44px / footer ≥12.5px。
  压高度靠留白与删内容，不靠缩字号。

## 5. 数字纪律

- 所有数字回源核对（源文件/看板原文），**禁止凭记忆填、禁止编造**。
- 战报（T4）数字必须带口径注释（MTD/YTD、截止日、来源看板）。
- 处罚金额、达标线必须与现行制度核对，不确定就在交付说明里问，不编。

## 6. 交付前自检清单

- [ ] 结构忠实：内容有的模块都在，内容没有的一个没加
- [ ] 全页无分隔线（grep border 检查：仅允许胶囊内部无、面板无边框）
- [ ] 标签全部胶囊化
- [ ] 有可图化的内容已经图示（流程/对比/构成/数量）
- [ ] 色板四角色未用错（绿=正向、朱砂=禁止、橙=注意、青蓝=结构）
- [ ] 高度默认 ≤1700px；内容密集页说明拉长原因
- [ ] 数字已回源核对；无编造的日期/处罚/责任人
